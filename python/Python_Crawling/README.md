# 🕷️ Python Crawling 학습 정리

> 웹 크롤링 기초부터 데이터 수집, 전처리, 시각화까지 학습 내용 정리

---

## 1. 크롤링 기초

- 웹 통신 기본 원리 : Client-Server, Request-Response 구조
- `requests` 라이브러리로 웹 페이지 정보 요청 및 응답 처리
- `Selenium` 라이브러리로 브라우저 직접 조작 (클릭, 입력, 스크롤 등)

---

## 2. 데이터 수집 실습

- 네이버 IT/과학 뉴스 헤드라인 제목 및 내용 수집
- ZDNet 뉴스 제목 및 URL 수집 → `DataFrame`으로 정리
- 멜론차트 Top 100 노래 제목 / 가수 이름 수집
- 한솥도시락 홈페이지 메뉴명 및 가격 수집
- 웹 페이지 이미지 수집 후 로컬 저장 (`os`, `urllib.request` 활용)
- 네이버 지도에서 맛집 리뷰 수집 (`iframe` 접근 방식)

---

## 3. 고객 경험 데이터 수집 및 분석

- 네이버 영화 리뷰 수집 → 텍스트 전처리 → 워드클라우드 생성
- 네이버 지식in : 키워드 검색으로 Q&A 데이터 수집 및 워드클라우드
- 네이버 카페 : URL 패턴 분석 → 키워드/기간 설정 → 본문 추출 → 텍스트 파일 저장
- 네이버 블로그 : 키워드 + 기간(6개월) 설정으로 블로그 글 수집 → 워드클라우드

---

## 4. 수집 데이터 결과물

- 엑셀 파일 : IT/과학 뉴스 데이터, 한솥 메뉴 정리
