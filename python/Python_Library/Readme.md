# 📊 Python Library 학습 정리

> Numpy, Pandas, Matplotlib, Seaborn을 활용한 데이터 분석 및 시각화 학습 내용 정리

---

## 1. Numpy

- 고성능 과학 계산을 위한 다차원 배열(`ndarray`) 사용법
- 파이썬 `list` 대비 빠르고 효율적인 산술 연산 처리
- 배열 속성 확인 : `shape`, `ndim`, `dtype`, `size`

---

## 2. Pandas

- 주요 데이터 구조 : `Series` (1차원), `DataFrame` (2차원)
- 기본 사용법 및 기술 통계 탐색
- 데이터 병합 및 정렬
- 결측치 처리 : `isnull()`, `notnull()`, `fillna()`
- `os` 라이브러리로 파일 시스템 관리 (현재 위치, 파일 목록 확인)
- 실습 데이터 : 직원 정보(hr-info.csv), 타이타닉, 연도별 범죄 데이터(2015~2017.csv)

---

## 3. 시각화 (Matplotlib / Seaborn)

- Pandas `plot` 함수로 간단한 시각화
- `matplotlib`, `seaborn`으로 커스터마이징 시각화
- 한글 폰트 설정 방법
- 실습 데이터 : 교통사고 데이터(2017), 개발자 연봉 데이터
