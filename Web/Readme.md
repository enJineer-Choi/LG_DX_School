# 🖥️ WEB_study 학습 정리

> Servlet, JSP, MyBatis를 활용한 Java 웹 개발 및 회원 관리 기능 구현 실습

---

## 1. 핵심 기술 스택

- **Servlet** : URL 요청을 받아 처리하는 Java 서버 컴포넌트
- **JSP** : Java 코드를 HTML에 삽입하여 동적 웹 페이지 생성
- **JSTL** : JSP에서 조건문/반복문을 태그로 처리 (`<c:if>`, `<c:choose>` 등)
- **MyBatis** : Java ↔ SQL 연결 (DB 연동 프레임워크)
- **Oracle DB** : 회원 데이터 저장 및 관리
- **Maven** : 프로젝트 빌드 및 라이브러리 의존성 관리 (`pom.xml`)
- **Tomcat** : 웹 애플리케이션 서버 (서블릿/JSP 실행 환경)

---

## 2. 구현 기능 (회원 관리 시스템)

- **메인 페이지** : 로그인/로그아웃 상태 표시, 회원가입 성공 메시지, 개인정보 수정 및 탈퇴 버튼
- **회원가입** : 아이디 / 비밀번호 / 닉네임 입력 → 서블릿으로 전송
- **로그인** : 아이디 / 비밀번호 입력 → 서블릿으로 전송
- **개인정보 수정** : 기존 정보 표시 (아이디 읽기 전용), 비밀번호 / 닉네임 수정
- **회원 탈퇴** : 탈퇴 처리

---

## 3. 환경 설정

- **web.xml** : 요청/응답 인코딩 UTF-8 설정, 서블릿 매핑 정보
- **server.xml** : Tomcat 서버 설정, 프로젝트별 Context Path 정의
- **pom.xml** : Maven 의존성 관리 (Servlet, ojdbc11, MyBatis, JSTL, Lombok)
